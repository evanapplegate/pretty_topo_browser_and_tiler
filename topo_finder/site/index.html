Orthophoto-topos:

in the late '70s and early '80s the U.S. Geological Survey made lovely 1:24k topos by laying green ink on land, blue on water over monochrome aerial imagery. Here’s a browser of these editions +/- some false positives, each with an S3 link to the full GeoTIFF. For more topos use TopoView. Here's the GitHub repo with scripts on color correcting and tiling them together. Another cute map project by Evan Applegate.
